# 📊 Mobile Sales Analysis Dashboard
## 📌 Project Overview

This project is an interactive **Mobile Sales Analysis Dashboard** created using **Microsoft Power BI**. The sales data was prepared and managed using **Microsoft Excel**, and Power BI was used to transform the data into meaningful visualizations and business insights.

The dashboard provides an overview of mobile sales performance based on brands, payment methods, cities, months, units sold, and average price.

## 🎯 Project Objective
The main objective of this project is to analyze mobile sales data and create an interactive dashboard that helps understand:
- Overall sales performance
- Monthly sales trends
- Brand-wise sales
- Payment method preferences
- City-wise sales distribution
- Total units sold
- Average selling price

## 🛠️ Tools & Technologies
- **Microsoft Excel** – Data preparation and storage
- **Power BI** – Dashboard creation and visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Calculations and measures
- **Data Visualization** – Charts, cards, maps, slicers

## 📊 Dashboard Features
### 🔹 KPI Cards

The dashboard displays important KPIs such as:
- **Total Units Sold:** 19K
- **Total Sales:** 3.835K
- **Average Price:** 40.11K

### 🔹 Monthly Sales Analysis
A line chart is used to analyze the **number of sales from January to December** and identify monthly sales trends.

### 🔹 Brand Analysis
The dashboard compares sales across major mobile brands:
- Apple
- Samsung
- OnePlus
- Vivo
- Xiaomi

### 🔹 Payment Method Analysis
The dashboard analyzes customer payment preferences using:
- UPI
- Debit Card
- Credit Card
- Cash

### 🔹 City-wise Analysis
A map visualization is used to analyze the geographical distribution of mobile sales across different cities in India.

### 🔹 Interactive Filters
Users can interact with the dashboard using filters such as:
- Month
- City

These filters allow users to explore the data based on specific requirements.
## 📈 Key Insights

Some of the insights available from the dashboard include:
- Comparison of sales performance across different mobile brands.
- Identification of monthly sales trends.
- Analysis of the most commonly used payment methods.
- Comparison of mobile sales across different cities.
- Monitoring of total units sold and average mobile price.
